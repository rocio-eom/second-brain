# (이관됨) ADR: Git 레포 topology·네이밍·CI 트리거 컨벤션

이 노트는 **platform-knowledge/notes/decisions/dec-2026-07-31-git-repo-topology-naming-convention.md** 로 이관됐다.

플랫폼 저장소의 규약 정본이 이 id 를 근거로 인용하는데 그 문서가 플랫폼 밖에 있으면
CI 도 감사도 그것을 볼 수 없다. 링크 무결성을 위해 자리만 남긴다 — 내용은 옮긴 쪽이 정본이다.
